## 2. 스터디 목표

### 2.1 개념을 직접 설명하며 체화하기

CS 개념은 혼자 공부할 수도 있지만, 스스로 말로 설명하는 과정에서 이해가 더 분명해진다.  
스터디에서는 발표와 답변 과정을 통해 각자 학습한 내용을 자기 것으로 만드는 것을 목표로 한다.

### 2.2 꼬리질문을 통해 면접에 대비하기

단순히 개념을 암기하는 데서 끝나지 않고, 관련 질문과 확장 질문까지 대비하는 연습을 한다.  
이를 통해 실제 면접과 유사한 상황에서 답변하는 힘을 기른다.

----

## 3. 진행 방식

### 3.1 사전 학습

- 모든 스터디원은 매주 정해진 챕터를 각자 학습한다.
- 각자 꼬리질문 3개를 준비한다.
- 준비한 질문에 대한 답변은 반드시 정확하게 조사해온다.
- 질문은 해당 챕터와 관련된 내용이면 되며, 아직 배우지 않은 부가 개념이 포함되어도 괜찮다.

### 3.2 발표

- 매주 발표자 1명이 발표를 진행한다.
- 발표 시간은 15분 내외로 한다.
- 시간 초과는 지양한다.
- 발표자는 매주 돌아가면서 맡는다.

### 3.3 면접형 질의응답

- 발표가 끝난 후, 한 명씩 돌아가며 1:3 면접 형식으로 진행한다.
- 면접관은 각자 준비한 질문 1개씩을 한다.
- 면접자는 총 3개의 질문에 답변한다.

## 5. 기록 방식

### 5.1 질문 및 답변 정리

- 모든 스터디가 끝난 후, 각자가 준비한 질문과 답변을 Wiki에 정리한다.
- 모든 스터디원은 정리된 질문과 답변을 바탕으로 2차 개념 학습을 진행한다.

### 5.2 주간 학습 기록 업로드

- 모든 스터디가 끝난 후, 각자는 1주일간 공부한 과정과 결과를 `.md` 파일로 작성하여 Wiki에 업로드한다.
