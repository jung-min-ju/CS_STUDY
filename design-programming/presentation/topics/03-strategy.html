무슨 패턴인가알고리즘(전략)을 각각 별도 클래스로 분리하고, 실행 시점에 원하는 전략으로 교체할 수 있게 합니다. if/else 분기 대신 객체를 바꿔 끼우는 방식이에요.
이 화면에서는Sorter(Context) 박스 아래에 BubbleSort·QuickSort·MergeSort 세 노드가 연결선으로 이어져 있습니다. "Bubble 설정" 등의 버튼으로 전략을 고른 뒤 "execute() 실행"을 누르면 선택된 전략이 정렬을 수행합니다.
언제 떠올리나같은 작업을 여러 방식으로 처리해야 하고, 런타임에 방식을 바꿔야 할 때. 결제 수단 선택, 파일 압축 알고리즘 교체 등이 대표적입니다.
Strategy pattern
interface SortStrategy {
sort(data): number[]
}
class Sorter {
private strategy: SortStrategy
setStrategy(s: SortStrategy) {
this.strategy = s
}
execute(data) {
return this.strategy.sort(data)
}
}
