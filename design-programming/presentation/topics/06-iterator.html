언제 떠올리나내부 구조가 다른 여러 컬렉션을 동일한 방식으로 순회해야 할 때. 예를 들어 DB 커서, 페이지네이션 결과, 파일 스트림을 같은 인터페이스로 읽어야 하는 상황.
Iterator pattern
interface Iterator<T> {
hasNext(): boolean
next(): T
}
class ArrayIterator implements Iterator {
private index = 0
constructor(private items: T[]) {}
hasNext() {
return this.index < this.items.length
}
next() {
return this.items[this.index++]
}
}
