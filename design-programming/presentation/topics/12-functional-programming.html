함수형 프로그래밍이란?
핵심 키워드 8개 — 클릭하면 코드 데모가 나타납니다
1. 순수 함수
같은 입력 → 항상 같은 출력, 부작용 없음
2. 불변성
원본 데이터를 절대 변경하지 않음
3. 일급 함수
함수를 값(숫자, 문자열)처럼 다룸
4. 고차 함수
함수를 인자로 받거나 반환하는 함수
5. 커링
인자를 하나씩 받아서 특화된 함수 생성
6. 함수 합성
작은 함수를 레고처럼 조립해서 큰 함수
7. 선언형 프로그래밍
HOW가 아닌 WHAT만 적음
8. 참조 투명성
함수 호출을 결과값으로 바꿔도 동일
