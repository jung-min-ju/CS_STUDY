무슨 패턴인가ViewModel이 상태와 변환 로직을 들고 있고, View는 그 상태를 바인딩해서 자동으로 다시 그려집니다. 수동으로 DOM을 갱신할 필요가 없어요.
이 화면에서는Model·ViewModel·View 세 박스와 바인딩 흐름 화살표가 표시됩니다. "+ 할 일 추가" 버튼을 누르면 State changes와 Renders 카운터가 함께 올라가며 자동 갱신을 확인할 수 있습니다.
언제 떠올리나React Hooks, Vue Composition API처럼 상태 변경이 UI에 자동 반영되는 프레임워크를 쓸 때. 폼 입력이 많거나 양방향 데이터 흐름이 필요한 화면에 적합합니다.
MVVM pattern (React로 비유한 예시)
// Model — 순수 데이터 + API
class TodoModel {
todos = []
addTodo(text) { this.todos.push({ text, done: false }) }
toggle(i) { this.todos[i].done = !this.todos[i].done }
}
// ViewModel에 비유할 수 있는 상태 로직 (React Hook)
function useTodoViewModel() {
const [todos, setTodos] = useState([])
const addTodo = (text) => {
model.addTodo(text)
setTodos([...model.todos])
}
return { todos, addTodo }
}
// View — 상태를 읽고 다시 렌더링
function TodoView() {
const { todos, addTodo } = useTodoViewModel()
return <ul>{todos.map(t => <li>{t.text}</li>)}</ul>
}
